# 《做出第一个 AI 应用》本地模拟示例

陈一豪策划，AI 辅助撰写，公开初稿配套代码。所有图书角制度、分机与版本数据均为虚构教学数据。

## 运行

需要 Python 3.10 或更新版本，无第三方依赖。进入此目录执行：

```sh
python3 app.py --question '借阅期限是多少？'
python3 app.py --question '逾期罚款多少钱？'
python3 app.py --question '管理员值班电话是什么？'
python3 -m unittest -v
```

第一问会引用 `borrow-v1`；第二问由于没有匹配资料返回 `insufficient_evidence`；第三问以公开访客身份访问时不会获得内部资料。命令行不提供身份切换参数，测试中由可信调用方传入 `group='staff'` 演示内部访问。

## 实际验证

2026-09-26，使用 Python 3.12.14 在本地运行：

- `python3 -m unittest -v`：13 项测试全部通过。
- 命令行借阅问题：返回教学借阅规则、`borrow-v1` 引用与 `mode: mock`。
- 未知问题、内部资料问题：均返回 `insufficient_evidence`，引用为空。

测试覆盖请求大小、JSON 解析、问题类型与长度、检索条数边界、身份字段拒绝、资料权限过滤、匹配次序、缺少证据、非法引用、不合格输出和适配器模拟故障。测试不评价真实模型的理解、推理、提示注入抵抗能力，也不代表线上性能。

## 结构与限制

`app.py` 把流程分成 `parse_request`、`retrieve`、`MockAdapter.generate`、`validate_response` 和 `answer`。检索使用手工关键词计分，生成只连接资料原句。因此会漏掉同义表达，也不能自动确认资料是否真的回答了完整问题。

`group` 是由可信调用者提供的演示参数，不是认证系统。真实接入需由经过验证的身份决定，不能从浏览器请求中的自报角色直接读取。引用校验只验证编号属于本次可访问资料，不验证每个事实是否受到来源支持。

程序不联网、不调用真实模型、不使用凭证、不启动服务器，不包含真实认证、并发管理、持久化、费用计量、超时重试或生产部署。若要接入外部模型，需要按官方文档实现新的适配器、调整并验证输出约定，然后运行真实场景评估。
