# 02 · 把三份资料整理成有来源的事实表

陈一豪 / Ethan · AI 辅助编写 · 公开首版 · 预计 40 分钟

练习区分建议、确认与未知，面对不同版本时保留依据，交付一张能追溯的资料清单。

**本课成果：** 一张四列事实表：事项、当前内容、证据状态、材料出处；另附待确认清单。

材料为虚构教学示例；参考答案是预编写示范，不是模型实测。可以先手动练习，再在自己选择的 AI 工具中尝试。

## 先理解

### 来源让判断可以被复查

同一句话如果出自讨论建议和正式确认，作用可能不同。记录材料标签与原句，能让别人看到你依据什么判断。无需复杂软件，纸面表格就可以承载来源。不能因为一句话听起来合理，就把它写成已经决定。

### 新版本不等于新决定

更新时间较晚只能说明文本更晚出现，不自动说明其中所有内容都已通过。应查看材料是否说明确认、替代或仍在讨论。两个有效记录冲突时，先保留冲突，不能擅自选一个更喜欢的答案。

### 把缺项保留到交接处

没有日期资料时，正确结果可以是“日期待确认”。事实表的目标是帮助继续工作，不是强行填满所有格子。每项未知最好指向一个需要回答的问题，而不是泛泛写“其他信息待定”。

## 练习材料

### 虚构材料 A｜早期建议

```text
建议将青禾阅读交流安排为 20 人、90 分钟；最好在线下进行。以上为讨论想法，尚未确认。
```

### 虚构材料 B｜负责人确认记录

```text
本次先按 12 人、45 分钟安排，采用线上形式，不收报名费。人数、时长和形式以这份记录为准，替代早期建议。具体日期、起止时间与报名方式尚待确认。
```

### 虚构材料 C｜稍后出现的群聊建议

```text
有人提议定在本周六 14:00，也有人建议使用某个会议平台。目前没有负责人回复确认，尚无会议链接。
```

## 动手实践

### 1. 先给资料贴上状态

在 A 旁写“早期建议”，B 旁写“确认且说明替代关系”，C 旁写“后续建议未确认”。这里的状态来自文字依据，而不是材料编号或出现顺序。

### 2. 按事项横向比较

把人数、时长、形式、费用、日期、报名方式各列一行。先找同一事项出现在哪里，再填当前内容。对于人数和时长，说明为什么采用 B，而不是只写一个数字。

### 3. 保留有意义的差异

在来源列留下“B 替代 A”的简短说明。日期一栏记录 C 的建议，但当前状态仍写待确认。这样别人既能看到进展，也能知道哪个问题仍需要负责人决定。

### 4. 用事实表回答两个问题

试着回答“本次是否线上”和“周六能否直接参加”。前者有明确依据，后者不足。将不能回答的问题整理成待确认清单，再决定是否自愿请 AI 帮忙排版。

## 可复制的任务说明

```text
请只依据下面的虚构材料，整理事项、当前内容、证据状态、材料出处四列表格，另列待确认问题。A：建议 20 人、90 分钟、线下，未确认。B：负责人确认本次 12 人、45 分钟、线上、不收报名费，人数时长形式以 B 为准并替代 A；日期、起止时间、报名方式待定。C：稍后有人建议本周六 14:00 使用某会议平台，负责人未确认，没有链接。不要把较晚建议当决定，不生成不存在的链接，保留替代关系。
```

## 判断练习

整理完材料后，哪句话可以直接写进内部草稿的“已确认信息”？

- a：本周六 14:00 在线上见，会议链接即将自动生成。
- b：因为 A 最完整，所以仍按 20 人、90 分钟、线下执行。
- c：本次按 12 人、45 分钟、线上形式安排，日期和报名方式待确认。

## 参考与解释

判断题参考：c。B 明确确认了人数、时长和形式，并说明替代 A，所以 C 有可追溯依据。选项 A 将未获确认的建议改成安排，还补了链接承诺；选项 B 忽略了明确的替代关系。

```text
事实表参考：人数＝12 人，已确认，B 替代 A；时长＝45 分钟，已确认，B 替代 A；形式＝线上，已确认，B 替代 A；报名费＝不收取，B；日期与起止时间＝待确认，C 仅提议周六 14:00；报名方式与会议链接＝待确认，B/C 未给出可用入口。
```

## 成果自评

- [ ] 每个关键结论都有材料标签或原句定位。
- [ ] 人数、时长和形式保留 B 替代 A 的依据。
- [ ] 周六 14:00 仍为建议，没有写成正式安排。
- [ ] 待确认清单能让下一位协作者逐项回答。

你遇到过“最新文件里仍有旧内容”吗？不需要公开私密材料，只写这种情况会影响哪项判断，以及以后准备保留什么版本标识。
