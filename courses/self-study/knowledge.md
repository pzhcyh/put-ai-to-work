# 10 · 用三份材料测试资料问答

陈一豪 / Ethan · AI 辅助编写 · 公开首版 · 预计 40 分钟

回答问题、解释冲突、承认缺口，让结论回到来源。

**本课成果：** 一份三材料索引、三类问题的答案卡，以及逐条核对记录。

材料为虚构教学示例；参考答案是预编写示范，不是模型实测。可以先手动练习，再在自己选择的 AI 工具中尝试。

## 先理解

### 新旧资料先确认效力

更新时间较晚，不等于已经生效。正式规则、旧版留档和志愿者建议地位不同。先识别状态与范围，再整理答案；模型不能替负责人批准仍处于建议阶段的变更。

### 答案带上来源与缺口

本课使用“简短答案、材料编号与句号、尚未确定内容”三栏。答案能够追溯，别人才能独立检查。原文没有回答的问题，应说明当前材料不足；不能把资料中没写收费，推成已经确认免费。

### 用三类问题检查边界

本课检查正常问题、版本冲突和缺少材料三种情况。先写预期，再比较 AI 输出，避免被流畅答案带着改变标准。小样本练习不代表已验证完整知识库。

## 练习材料

### 材料 A：旧规则 v1，已过期

```text
A1：共学站图书角原定每周日十四点至十五点开放。A2：原借阅期限为七天。本材料仅作历史留档，开放时间与借期已由材料 B 替代。人物和规则均为虚构教学设定。
```

### 材料 B：现行规则 v2，负责人已确认

```text
B1：图书角每周日十五点至十六点开放。B2：借阅期限为十四天。B3：本版替代旧版的开放时间与借期；其他未写事项仍需另行确认。
```

### 材料 C：志愿者建议，未批准

```text
C1：建议把借期延长为二十一天，便于慢慢阅读。C2：该建议记录晚于 B，但尚未得到负责人确认。三份材料都没有说明逾期费用或续借规则。
```

## 动手实践

### 1. 建立最小来源表

记下材料编号、状态和范围：A 是历史，B 是现行依据，C 是建议。保留原文，不用混合摘要覆盖它们，方便以后追查错误。

### 2. 先写三类预期答案

依次回答：现在周日几点开放；最新建议是否意味着可以借二十一天；逾期一天收多少钱。每题写出所依赖的句子，第三题应明确无足够依据。先完成手工答案，再使用外部 AI 工具比较，页面本身不会提交材料给模型。

### 3. 检查引用是否真的支持结论

复制材料与提示词，要求按三栏回答。回到原文核对引用是否存在、句意是否一致，有无擅自填金额或批准建议。编号只能帮助定位，不能证明答案正确。

### 4. 做一次缺资料测试

另开一轮仅含 A 和 C 的独立测试，不带上先前回答，并把问题限定为“仅凭这两份材料能否确认现行借期”。A 已过期，C 未批准，参考结果应是不能确认。保留两轮材料清单，解释为何第二轮不能沿用十四天。

## 可复制的任务说明

```text
请仅依据我附上的共学站材料回答三个问题：现行周日开放时段是什么；C 的最新建议是否已经把借期改成二十一天；逾期一天收多少钱。先识别 A、B、C 的状态，再按“答案｜材料编号与具体句子｜缺口”输出。不要把较晚的建议当批准，不把资料未写解释成免费，不调用外部常识补规则。若证据不足，说明需要确认的事项。
```

## 判断练习

C 比 B 更新，但 C 明确未批准，目前应怎样回答借阅期限？

- a：仍为十四天，依据现行规则 B2，并说明 C 只是建议。
- b：改为二十一天，因为最新信息优先。
- c：取七天、十四天、二十一天的平均值作为规则。

## 参考与解释

判断题参考：a。B 是已确认现行规则，C 没有批准效力。规则由有效来源确定，不能按更新时间或数值平均自行决定。

```text
答案卡示例：①每周日十五点至十六点开放，依据 B1。②目前仍借十四天，依据 B2；二十一天只是 C1 的建议，C2 说明未批准。③当前材料无法确定逾期费用，应向规则负责人确认；不能回答免费或编造金额。缺资料测试：只剩已过期 A 与未批准 C 时，现行借期无法确认。检查引用时，应能逐字找到相应句子，并确认结论没有扩大原句范围。
```

## 成果自评

- [ ] 原始三份材料保留，来源表明确历史、现行与建议状态。
- [ ] 三类问题均有答案卡，能够定位支撑句子或说明缺口。
- [ ] 没有把未批准建议写成规则，也没有推断免费。
- [ ] 缺资料测试单独记录输入，结论承认无法确认现行借期。
