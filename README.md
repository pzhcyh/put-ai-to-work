# 把 AI 用起来

**普通人的学习、工作与创造实践**

陈一豪 / Ethan · 把 AI 讲明白，把事情做出来。

这本书写给想把 AI 用到具体事情里的普通人。从一个今天就能开始的小任务出发，逐步练习表达问题、提供材料、核实回答、组织协作，并完成自己的第一件作品。

不需要先会编程。请带着一件真实的小事来读，读完一章，做一次练习，再决定下一步。

> 当前版本：2026-09-26 首轮公开初稿，共十二章。书稿由陈一豪策划，结合既有分享方向与 AI 辅助整理，仍在持续审阅和修订。文中教学示例不代表真实客户或活动成果。

## 怎样使用这本书

1. 选一个你真正想完成、并且能够检查结果的小任务。
2. 阅读对应章节，完成章末“轮到你试一试”。
3. 留下初稿、检查意见和修改结果，不只保存最后的答案。
4. 分享你实际验证过的内容，同时说明尚未确认的地方。

工具和模型会改变，先说清楚目标、检查依据、保留自己的判断，这些习惯可以反复使用。

## 基础课配套讲义

四节讲义均为可独立阅读的教学设计，等待实际试学反馈；不是已开课或学习效果的证明。

1. [检查一份通知草稿](lessons/first-ai-task.md)：交代任务、核对资料、给出修改。
2. [三份资料，哪些能写进通知](lessons/02-materials.md)：区分确认记录、建议和待确认项。
3. [把模糊意见变成可执行反馈](lessons/03-revision.md)：修订一份活动流程并记录依据。
4. [完成一件可试用的小作品](lessons/04-first-work.md)：留下作品、试用记录与一次改进。

进阶课程沿真实任务长期延伸，八个起始主题不是完整学习周期。
