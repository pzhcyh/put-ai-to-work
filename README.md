# 把 AI 用起来

**普通人的学习、工作与创造实践**

陈一豪 / Ethan · 把 AI 讲明白，把事情做出来。

这本书写给想把 AI 用到具体事情里的普通人。从一个今天就能开始的小任务出发，逐步练习表达问题、提供材料、核实回答、组织协作，并完成自己的第一件作品。

不需要先会编程。请带着一件真实的小事来读，读完一章，做一次练习，再决定下一步。

> 当前版本：2026-09-26 首轮公开初稿，共十二章。书稿由陈一豪策划，结合既有分享方向与 AI 辅助整理，仍在持续审阅和修订。文中教学示例不代表真实客户或活动成果。

## 怎样使用这本书

1. 选一个你真正想完成、并且能够检查结果的小任务。
2. 阅读对应章节，完成章末“轮到你试一试”。
3. 留下初稿、检查意见和修改结果，不只保存最后的答案。
4. 分享你实际验证过的内容，同时说明尚未确认的地方。

工具和模型会改变，先说清楚目标、检查依据、保留自己的判断，这些习惯可以反复使用。

## AI 自学实践营

[开始前读一篇：《AI 时代如何自学》](articles/ai-self-study.md)。参考李笑来《自学是门手艺》与 Dwarkesh Patel 的学习经验，提供原创六步实践、七天起步安排、可核对的数据练习和学习卡。文章区分个人经验、研究结果与教学建议，保留原始来源。

[完整课程与讲义](courses/self-study/README.md) 提供三条路线、12节自学实践课：

- AI入门：任务说明、资料判断、修改与交接。
- 工作应用：文案、表格、汇报与研究。
- 开发与工作流：小页面、资料问答、流程模拟与作品集。

每节包含短讲、虚构材料、任务说明、判断题、参考成果和自评清单。无需注册本站，实际AI对话可在读者自行选择的工具中完成；本站不调用模型或自动评判作品。在线进度仅保存在读者当前浏览器，可导出个人实践记录。此仓库只含公开课程内容，不含读者记录。

这套课程为AI辅助编写的公开首版，仍需试学反馈；原夜校基础与长期进阶主题保留。结构化数据见 [self-study.json](data/self-study.json)。
